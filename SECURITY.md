# Security Policy

## Report a vulnerability privately

Please do not open a public issue for a suspected security problem. Use
[DraftCenter's private vulnerability reporting form](https://github.com/roblebaegaming/DraftCenter/security/advisories/new)
so the report and follow-up remain confidential.

Include the affected page or component, the likely impact, and the minimum steps
needed to reproduce the problem. Use test data only. Do not access or change
another person's account or league, send real notifications, perform load tests,
or copy private user data while investigating.

If the report includes a secret, credential, or personal information, describe
where it was found without placing the value in the report title or any public
channel.

## Supported version

Security fixes are applied to the current production release and the `main`
branch. Older deployments and forks are not supported.

## Response

The project owner will acknowledge a report as soon as practical, validate its
scope, and coordinate a fix and disclosure timeline with the reporter. Please
allow time for a safe production fix before publishing technical details.
